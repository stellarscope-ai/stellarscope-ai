# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - Unreleased

### Added

- Monorepo scaffold (Turborepo + pnpm)
- Next.js web application with landing page
- Shared types and Zod schemas (`@stellarscope/shared`)
- Stellar data layer stubs (`@stellarscope/stellar-data`)
- Analytics engine stubs (`@stellarscope/analytics`)
- AI orchestration stubs with provider-agnostic interface (`@stellarscope/ai`)
- Supabase database schema with RLS policies
- Soroban watchlist subscription contract scaffold
- GitHub Actions CI pipeline
- Issue templates, PR template, contributing guide
